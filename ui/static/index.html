工作原理

候选 IP = 运行时向本机 mosdns 实时解析目标域名所得的真实 IP + 种子兜底 IP； 再对每个候选做 TCP 直连延迟探测，选最低者写入 hosts。 全程不依赖任何外部下载或代理，因此不会出现"拉不下来"。

覆盖方式

将自定义种子挂载到容器内对应路径即可覆盖；或在 /data 卷保留长期运行数据。 镜像本身只含公开种子，不含任何个人数据。

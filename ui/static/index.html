工作原理

          

            候选 IP = 运行时向本机 mosdns 实时解析目标域名得到的 A + AAAA 记录，再加种子兜底 IP；
            先做 TCP 延迟粗筛，再用真实 HTTPS 请求（SNI / Host 都是目标域名）逐个校验，
            剔除 Cloudflare 1034、证书不符、5xx 的 IP，最后按延迟取前 N 个写入 hosts。
            全程不依赖任何外部下载或代理，因此不会出现"拉不下来"。
          

        

        

          
覆盖方式

          

            将自定义种子挂载到容器内对应路径即可覆盖；或在 /data 卷保留长期运行数据。
            镜像本身只含公开种子，不含任何个人数据。

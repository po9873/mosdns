IP 源 （勾选启用 · 定时拉取 · 自动增删候选）

官方源最权威、只给网段；第三方更新快、量小；镜像用于 raw 直连不通时兜底。 只有勾上「启用」的源参与定时拉取和优选，取消勾选立即停止使用。

体检会逐个拉一次所有源（不只启用中的）。官方源失败只标红——它是权威定义，多半只是临时断网； 第三方/镜像源连续失败 3 次自动停用，避免每轮白等超时，恢复后手动勾回即可。

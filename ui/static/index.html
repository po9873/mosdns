优选参数

并发线程0 = 自动（按 CPU 与虚拟化自适应）
每路保留 IP 数只留最快的那批（延迟不超过最快的 1.5 倍），最多 N 个写入 hosts
每路最少保留上面那批不足这个数就从池里补历史验证过的备胎；防止一路只剩 1 个 IP，坏了没得换
同时优选 IPv6解析 AAAA 并按延迟探测；目标站有 IPv6 时会一起写入 hosts
HTTPS 校验（排除 1034）用真实 TLS + Host 请求验证，Cloudflare 1034、证书不符、5xx 的 IP 一律剔除
稳定期小时数这段时间内当前 IP 能打开且不慢就不再全量优选；0 = 每轮都重扫
慢到什么程度就换真实 HTTPS 响应时间超过这个值（毫秒）就重新优选；默认 1200
吞吐下限实测下载低于这个值（KB/s）也算变慢；0 = 不看吞吐，默认 200
结果变化后自动重载引擎一轮七路跑完只判断一次；结果和上轮相同则不重启，DNS 零中断

IP 源 （勾选启用 · 定时拉取 · 自动增删候选）

官方源最权威、只给网段；第三方更新快、量小；镜像用于 raw 直连不通时兜底。 只有勾上「启用」的源参与定时拉取和优选，取消勾选立即停止使用。

体检会逐个拉一次所有源（不只启用中的）。官方源失败只标红——它是权威定义，多半只是临时断网； 非官方源拉不到就按上面的开关处理：删除（默认，1 次不通过就删） 或只停用。删掉的源会从候选池里一并带走它还没验证过的 IP，已验证过、实测能通的 IP 保留。
